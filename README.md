# 문자열 덧셈 계산기

# 기능 목록

## 문자열 입력 받기
- 구분자와 양수로 구성된 문자열 입력 받기
- 구분자의 조건
  - 쉼표(,) 또는 콜론(:)을 기본 구분자로 지정
  - 커스텀 구분자: 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자
  - ex) `"//;\n1;2;3`을 입력할 경우 커스텀 구분자는 세미콜론(;)이고, 반환 값은 6
- 유효성 검사
  - 구분자와 양수 이외의 문자 입력 제한
  - 빈 입력 제한
  - 구분자가 연속으로 입력 제한
  - ex) "1,,2" => error
  - 문자열에 공백 포함 불가

## 계산 기능
- 입력된 문자열에 커스텀 구분자가 있는지 확인
- 커스텀 구분자가 있는 경우
  - 커스텀 구분자와 기본 구분자를 구분자로 하여 양수를 각각 분리
  - 분리한 양수를 더하기
- 커스텀 구분자가 없는 경우
  - 기본 구분자를 구분자로 하여 양수를 각각 분리
  - 분리한 양수를 더하기

## 결과 출력하기 
- "결과 : " + 계산 값 형태로 출력

## 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
